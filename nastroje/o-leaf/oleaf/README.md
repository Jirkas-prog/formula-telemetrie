# O-Leaf

O-Leaf je offline LaTeX editor pro Home Assistant OS. Po instalaci se otevírá
přes Home Assistant Ingress a může být zobrazen v postranním panelu.

Verze 0.8 přináší vzhled WorkFlow Angular a přímou práci se složkami na
Home Assistantu. V **Otevřít projekt → Složka v Home Assistantu** můžete
otevřít existující projekt z `/media` nebo `/share`. V **Nastavení → Složky
projektů** si zvolte výchozí umístění, například `/media/projekty/latex`.
Stejná složka se nabídne při vytváření nového projektu. Původní soukromé
projekty i import a export ZIP zůstávají dostupné.

Vedle LaTeXu umí v pracovním panelu otevřít libovolný projektový soubor:
editovat UTF-8 text, plynule zobrazit PDF a obrázky, přehrát audio/video nebo
bezpečně prohlédnout a stáhnout neznámá binární data.

Podrobnosti najdete v záložce Dokumentace addonu nebo v `DOCS.md`.
